# PLAYROOM · CodeHive Games

설치나 회원가입 없이 즐기는 일곱 가지 브라우저 게임입니다. 루트 `index.html`에서 게임을 선택합니다. 기존 `racing/`, `minecraft/`, `BlueMarble/`, `ladder/` 주소를 유지하고, `breakout/`의 네온 브레이커, `gunarcade/`의 GunArcade, `unicornruns/`의 Unicorn Runs를 제공합니다.

## 실행

저장소 루트에서 Python 3의 정적 서버를 실행하세요.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. Windows에서는 `py -m http.server 8000`도 사용할 수 있습니다. ES 모듈을 사용하므로 HTML 파일을 더블클릭하는 `file://` 실행은 지원하지 않습니다. 게임별 Windows 서버 스크립트는 기존 3D 게임 경로에 그대로 있습니다. 일곱 게임을 함께 이용할 때는 **저장소 전체를 루트로 서빙**하세요. 보드게임은 `minecraft/libs/three.module.js`를 공유합니다.

Nginx 등 정적 호스팅에 저장소 전체를 올려도 실행할 수 있습니다. 별도 Node 빌드, 외부 CDN, API 키, 데이터베이스가 필요하지 않습니다. HTTPS 또는 localhost에서 최신 WebGL 지원 브라우저와 하드웨어 가속을 사용하세요.

게임룸의 액션/보드게임 필터로 게임을 찾을 수 있습니다. 보드게임은 WebGL을 사용할 수 없으면 2D로 계속 플레이합니다. Unicorn Runs, GunArcade, 레이싱과 블록 마을은 WebGL이 필요하며 사용할 수 없으면 안내를 표시합니다. 모바일 레이싱은 1인 터치 플레이를 지원하며, 같은 기기 2인 모드는 키보드를 권장합니다.

### Unicorn Runs — 유니콘 3D 레이싱

`unicornruns/`에서 맵을 고릅니다. 숲·구름·별빛의 서로 다른 코스는 각각 1·2·3바퀴이며 최대 3바퀴입니다. 출발 버튼을 누르면 **3 → 2 → 1 카운트다운** 동안 유니콘은 움직이지 않으며 경기 시간도 흐르지 않습니다. 카운트다운이 끝나면 직접 가속하여 달립니다.

W/위 화살표 또는 화면의 RUN 버튼을 누르고 가속합니다. S/아래 화살표/BRAKE는 감속, AD/좌우 화살표는 차선 이동입니다. 유니콘은 코스 방향을 따라 달리고, 길 밖에서는 속도가 줄어듭니다. 실제 코스 주행 거리를 누적해 바퀴를 판정하므로 좌우 이동으로 완주를 건너뛸 수 없습니다.

모든 바퀴를 완료하면 기록을 표시하고 **3초 후 맵 선택 화면으로 자동 복귀**합니다. 버튼으로 즉시 복귀할 수도 있습니다. 다음 경기는 바퀴·시간·속도·입력을 초기화하고 다시 3초 카운트다운으로 시작합니다. 최근 완주 기록은 화면에 유지되며 새로고침 시 초기화됩니다. 전체화면, 터치, 효과 줄이기, 일시정지와 WebGL 복구를 지원합니다. 창 이탈·탭 숨김 시 카운트다운과 경기 및 자동 복귀 시간이 정지됩니다.

### GunArcade — 스테이지형 3D 슈팅

`gunarcade/`에서 시작합니다. 기동 정찰병 카이, 중장갑 돌격병 브릭, 균형형 레인저 아린, 테크 엔지니어 노바 중 선택합니다. 체력·공격력·이동 속도·기술 능력이 다르며, 획득 무기의 피해량은 공격력에, 발사 속도와 일부 무기의 탄 수는 기술 능력에 비례합니다.

매 스테이지는 **30초 준비 시간**으로 시작합니다. 이동하여 무기 상자에 닿으면 라이플·샷건·레일건·블래스터를 획득합니다. 최대 세 슬롯이며 같은 종류의 높은 등급은 강화하고, 슬롯이 가득 차면 현재 선택한 슬롯을 교체합니다. 무기를 하나도 얻지 못하면 준비 종료 시 실패하므로 시작 지점 앞의 라이플부터 확보하세요.

준비 시간이 끝나면 플레이어의 현재 위치 주변에서 적이 등장해 추격합니다. 모든 적을 물리치면 3초 뒤 다음 스테이지로 자동 이동하거나 버튼으로 바로 진행합니다. 다음 스테이지에서는 **이전 무기와 탄환을 초기화**하고 체력을 회복한 뒤 다시 30초 수집을 시작합니다. 점수는 유지됩니다. 적 수·체력·속도가 증가하고 원거리 적과 3스테이지마다 보스가 등장합니다.

자동 조준·자동 사격은 기본으로 켜져 있으며 설정에서 끌 수 있습니다. 수동 조준은 포인터 위치, 사격은 Space·마우스 누르기·터치 사격 버튼으로 합니다. 무기는 1–3 또는 화면의 슬롯 버튼으로 선택합니다. 전체화면 안에서도 상태·무기·터치 조작을 사용할 수 있습니다. 창 이탈과 탭 숨김은 자동 정지하며 준비 시간과 스테이지 전환도 멈춥니다. WebGL 오류 시 안내 후 렌더러 재시도를 제공하며, 진행은 메모리에만 유지됩니다.

### 네온 브레이커 — 진화형 벽돌깨기

`breakout/`에서 시작합니다. 화면의 2D/3D 버튼은 **같은 게임 진행 상태**를 유지하며 렌더링만 바꿉니다. 3D는 입체 보드·벽돌·공·아이템과 기울어진 카메라를 사용하고, WebGL 사용이 불가능하면 2D로 전환합니다. 마우스·터치의 좌표는 각 화면의 실제 보드에 투영되므로 두 모드에서 동일하게 패들을 조작할 수 있습니다.

떨어지는 아이템은 패들로 받습니다. 멀티볼은 공을 두 개 추가(최대6), 관통은8초, 레이저·패들 확장은10초, 슬로 필드는8초입니다. 실드는 최대3회 하단 반사, 생명 회복은 최대6개입니다. 레이저는 Space 또는 발사 버튼을 누르고 사용합니다. 멀티볼 중에는 마지막 공까지 잃어야 생명이 차감됩니다.

장갑 벽돌의 체력을 여러 번 깎고, 폭발 벽돌의 연쇄 반응과 움직이는 벽돌을 활용합니다. 3스테이지마다 움직이는 다중 체력 보스가 등장합니다. 연속 타격은 콤보 점수를 높입니다. 모든 벽돌을 부수면 공격력·패들 너비·패들/레이저 속도·아이템 확률 강화 또는 즉시 생명 보충 중 제공된 선택지를 고릅니다. 영구 강화는 해당 게임 동안 누적되며 새 게임에서 초기화됩니다. 높은 스테이지에서는 공 속도와 벽돌 체력이 증가합니다.

기기별 최고 점수는 브라우저 저장소에 저장하며, 저장이 차단되어도 플레이할 수 있습니다. 효과음은 사용자가 게임을 시작한 뒤 Web Audio로 합성합니다. **효과 줄이기** 설정과 시스템 모션 감소 설정을 지원합니다. 전체화면·일시정지·새 게임을 제공하고 창 이탈·탭 숨김 시 자동 정지합니다. 진행 상태와 강화는 새로고침 시 초기화됩니다.

### 보드 전체화면

블루마블과 사다리의 **전체화면 보기** 버튼은 보드만 크게 표시합니다. 우측 상단에 게임 조작과 닫기 버튼을 제공하며 버튼 비활성 상태와 현재 차례가 원래 게임과 동기화됩니다. 블루마블의 도시 구매·건설 창은 전체화면 안에서도 열립니다. 3D와 2D 모두 지원합니다. 네이티브 Fullscreen API가 제한된 모바일/임베드 환경에서는 브라우저 안의 화면 채우기 방식으로 전환합니다. 닫기 버튼으로 원래 화면으로 돌아가고, 네이티브 전체화면에서는 브라우저의 Esc로도 나갈 수 있습니다.

### 블록 마을 캠페인

성공 화면의 **다음 미션**으로 진행합니다. 지도 가로·세로 길이, 빛나는 조각 수, 그림자 수호자 수는 이전 미션의 1.5배이며 개수는 올림합니다. 제한시간은 1.25배 후 올림하고, 수호자의 능력도 강화해 지도 확장보다 시간 증가가 느리도록 구성했습니다.

| 미션 | 지도 가로×세로 | 조각 | 수호자 | 제한시간 |
|---|---|---:|---:|---:|
| 1 | 40×40 | 8 | 3 | 120초 |
| 2 | 60×60 | 12 | 5 | 150초 |
| 3 | 90×90 | 18 | 8 | 188초 |

실패 후 재도전, R, 재시작 버튼은 현재 미션을 반복합니다. 새로고침하면 미션 1부터 시작합니다. 지도와 오브젝트는 실제로 확장되며 조각·수호자를 인스턴싱하고 이전 지도 자원을 정리합니다. 미션이 계속 커지므로 높은 단계의 성능은 기기 사양에 따라 달라질 수 있습니다.

레이싱 기록은 지원되는 기존 `/api/records` 서버와 연동하고, 해당 API가 없는 정적 호스팅에서는 브라우저에 저장합니다. 브라우저 저장소가 차단되면 기록 저장을 보장하지 않습니다. 서버 기록 API는 저장소의 기존 PowerShell 서버 구현을 참고하세요. 다른 게임의 플레이 상태는 메모리에만 유지되며 새로고침 시 초기화됩니다.

## 검증

Python 3와 Node.js 22 이상에서 아래 검증을 실행할 수 있습니다. 추가 패키지가 필요하지 않습니다.

```bash
python tests/check.py
```

개별 검증은 `tests/`와 각 게임 디렉터리의 테스트 파일을 실행하세요. GitHub Actions도 동일한 검증 명령을 사용합니다. 테스트는 정적 리소스 연결, 실제 게임 상태 로직과 Three.js 수학/객체 초기화를 확인합니다. DOM/렌더러 어댑터를 사용하는 테스트는 브라우저의 실제 WebGL 출력이나 GPU 성능을 검증하지 않습니다.

배포 전에 실제 데스크톱/모바일에서 각 게임을 시작하고, 이동/턴 진행, 일시정지와 새 게임, 승리/종료, 2D 전환을 확인하세요. 이번 작업 환경에서는 실제 브라우저와 GPU로 화면을 확인하지 못했습니다.
