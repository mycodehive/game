# PLAYROOM · CodeHive Games

설치나 회원가입 없이 즐기는 네 가지 브라우저 게임입니다. 루트 `index.html`에서 게임을 선택합니다. 기존 `racing/`, `minecraft/`, `BlueMarble/`, `ladder/` 주소를 유지합니다.

## 실행

저장소 루트에서 Python 3의 정적 서버를 실행하세요.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. Windows에서는 `py -m http.server 8000`도 사용할 수 있습니다. ES 모듈을 사용하므로 HTML 파일을 더블클릭하는 `file://` 실행은 지원하지 않습니다. 게임별 Windows 서버 스크립트는 기존 3D 게임 경로에 그대로 있습니다. 네 게임을 함께 이용할 때는 **저장소 전체를 루트로 서빙**하세요. 보드게임은 `minecraft/libs/three.module.js`를 공유합니다.

Nginx 등 정적 호스팅에 저장소 전체를 올려도 실행할 수 있습니다. 별도 Node 빌드, 외부 CDN, API 키, 데이터베이스가 필요하지 않습니다. HTTPS 또는 localhost에서 최신 WebGL 지원 브라우저와 하드웨어 가속을 사용하세요.

## 게임과 조작

| 게임 | 플레이 | 목표 / 조작 |
|---|---|---|
| 에이펙스 레이싱 | 1인 또는 같은 기기 2인, 실제 Three.js + Cannon 물리 | 코스를 완주하고 기록 경쟁. 1인 WASD/방향키, Space 핸드브레이크, Q 부스트, R 복귀. 2인 모드는 화면의 조작 안내를 따르세요. |
| 블록 마을 모험 | 1인, 실제 Three.js 3D | 120초 안에 황금 조각 8개를 수집하고 시작 포털로 복귀. WASD/방향키 이동, Space 파동, Esc 일시정지. 터치 패드 지원. |
| 블루마블 | 같은 기기 2–4인, 실제 3D 보드와 2D 지도 | 도시 매입·건설·임대료·파산으로 승부. 화면 버튼으로 진행. 3D 보드 드래그 회전, 휠/버튼 확대, 도시 클릭 정보. |
| 사다리 어드벤처 | 같은 기기 2인, 실제 3D 보드와 2D 지도 | 정확히 100칸에 먼저 도착. 주사위 버튼 또는 빈 영역에서 Space. 사다리는 상승, 미끄럼은 하강, 100 초과는 제자리. 드래그/버튼 시점 회전. |

게임룸의 액션/보드게임 필터로 게임을 찾을 수 있습니다. 보드게임은 WebGL을 사용할 수 없으면 2D로 계속 플레이합니다. 레이싱과 블록 마을은 WebGL이 필요하며 사용할 수 없으면 안내를 표시합니다. 모바일 레이싱은 1인 터치 플레이를 지원하며, 같은 기기 2인 모드는 키보드를 권장합니다.

레이싱 기록은 지원되는 기존 `/api/records` 서버와 연동하고, 해당 API가 없는 정적 호스팅에서는 브라우저에 저장합니다. 브라우저 저장소가 차단되면 기록 저장을 보장하지 않습니다. 서버 기록 API는 저장소의 기존 PowerShell 서버 구현을 참고하세요. 다른 게임의 플레이 상태는 메모리에만 유지되며 새로고침 시 초기화됩니다.

## 검증

Python 3와 Node.js 22 이상에서 아래 검증을 실행할 수 있습니다. 추가 패키지가 필요하지 않습니다.

```bash
python tests/check.py
```

개별 검증은 `tests/`와 각 게임 디렉터리의 테스트 파일을 실행하세요. GitHub Actions도 동일한 검증 명령을 사용합니다. 테스트는 정적 리소스 연결, 실제 게임 상태 로직과 Three.js 수학/객체 초기화를 확인합니다. DOM/렌더러 어댑터를 사용하는 테스트는 브라우저의 실제 WebGL 출력이나 GPU 성능을 검증하지 않습니다.

배포 전에 실제 데스크톱/모바일에서 각 게임을 시작하고, 이동/턴 진행, 일시정지와 새 게임, 승리/종료, 2D 전환을 확인하세요. 이번 작업 환경에서는 실제 브라우저와 GPU로 화면을 확인하지 못했습니다.
